## 若出现 Environment not found / -501000

说明小程序连错了云环境，按序核对：

1. **重新编译**：本机 `git pull && cd apps/miniprogram && npm run build:weapp`，开发者工具点「编译」
2. **AppID**：详情里必须是 `wx47bde352ad9b3c36`（不要游客模式）
3. **环境 ID**：云开发控制台 → 设置 → 复制「环境 ID」  
   当前代码里是 `capable-porcupine-d1ddjw55abb0c2`。若控制台显示的不一样，把正确 ID 发我
4. **云函数目录选环境**：左侧 `cloudfunctions` 右键 →「当前环境」→ 选同一环境
5. **云函数已上传**：`roomRelay` 等 4 个都要「上传并部署：云端安装依赖」成功
